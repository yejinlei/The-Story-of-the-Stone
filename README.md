# 红楼未完

> 一恨鲥鱼多刺，二恨海棠无香，三恨《红楼》未完。
> ——张爱玲《红楼梦魇》

**在线阅读（GitHub Pages，纯静态、零后端）：<https://yejinlei.github.io/The-Story-of-the-Stone/>**

---

## 一、初衷

《红楼梦》只留下脂本前八十回，后文由程伟元、高鹗补缀而成。「兰桂齐芳」「沐皇恩」「延世泽」这类团圆笔法，与脂批所伏的「悬崖撒手」「泪尽夭亡」「狱神庙」「抄没」诸事处处相犯——**续的是书，走的却是反路**。

本项目想做一件朴素又狂妄的事：

1. **只认脂本。** 以《红楼梦脂评汇校本》为唯一权威，正文与甲戌、己卯、庚辰、戚序、蒙府、列藏、杨藏、甲辰八本脂批一并录入；程高本后四十回**一概不取，只作被批判的对象**。
2. **把「红学」变成可复算的工程。** 伏线、时序、诗风、人物结局，不再停留在文章里的感悟，而要落成可查询、可校验、可反驳的结构。
3. **让补完过程本身可见。** 不是一键生成一段「后四十回」，而是让批者、作者、红学诸家与计量方法当众吵架，把分歧、证据与裁决全部留在站上，读者可自行判断哪一回写得像、哪一回露了怯。

一句话：**以脂本为法度，以本体论为约束，以多 Agent 质证为方法，把第八十一回以下的推演与续写做成一部「带批语、带证据、带门禁」的公开稿。**

## 二、创新之处

**1. 按字体而非标点重建文本**
PDF 里宋体 12pt 是正文、楷体带色是脂批、楷体 9pt 黑字是校记。程序据此切出「回 → 块」结构，连批语里的**版本略字**（EUDC 私用区字符）也逐一还原成「甲戌·侧批」「庚辰·眉批」——4649 条脂批条条可溯源到版本。

**2. 本体论先于续写**
人物（情榜、册籍、探佚结局）、地点、器物、概念、意象、典故、诗社、节令、伏笔—结局，共构成本体库；另有 129 条人物关系。**先立规矩，后动笔**：写之前，人物的结局已经写定。

**3. 五道闸门（`honglou/guard.py`）**
| 闸门 | 内容 |
|---|---|
| G1 | 程高本禁例：中举、兰桂齐芳、焚稿、还魂、沐皇恩……一见即驳 |
| G2 | 时序：本回尚未发生的大事不得提前出现 |
| G3 | 已故人物不得再出场理事、说话（死亡名单滚动累积） |
| G4 | 诗风：某人作诗须合其诗风画像（黛玉哀婉、宝钗不哀艳、湘云不缠绵） |
| G5 | 接地：正文人名地名须在本体库中可查，查不到即为幻觉候选 |

**4. 文体门禁：把「像不像曹雪芹」做成可复算的指标**
句长均值、对话率、虚词率，加一张现代词禁例表（梦想、鼓励、氛围、情绪、她/她们、因为…所以…）。续写稿要跟脂本末十一回的基准比距离，**不合格就由「文体计量学家」出具修改指令、重写，最多三稿**；每回都公开「风格距离」与现代腔违例。

**5. 十一个 Agent 分三组互相质证**
古典组（脂砚斋、畸笏叟、曹雪芹）、红学组（周汝昌探佚、俞平伯考据、蔡元培索隐、张爱玲文心）、技术组（数据科学家、文体计量学家、知识图谱工程师），由主持人裁决。每五回为一「段落」，落笔前诸家先辩一次，八场共 80 条发言与裁决书全数落盘。

**6. 续写也被脂砚斋批点，且批语就近系句**
AI 代笔之后，脂砚斋照旧夹批——它也会骂：「错矣！麒麟乃湘云之物，何妄系黛玉？」「荒唐！顽石只一，何分二体？」175 条夹批按**去标点定位**就近挂在所批之句之后（5 条凭记忆改述的摘句，用最长公共子串模糊回锚，标「摘句微异」），体例与前八十回一致。

**7. 自绘本体图谱，七重视图**
无外部图表库，力导向布局自己算：人物关系、意象、诗词作者、伏笔—结局、时序、概念典故、居所地理。点任一节点，看它的逐回分布条形与详情面板。

**8. 字镜：把正文压成字符模型，可拟笔、可辨体**（`mirror.html`）
正文、脂批、诗词分别压成**字符三元组模型**（连同句读标点一起建模，约 6 万字表），浏览器端即可马尔可夫接笔，得「雪芹正文 / 脂砚斋批 / 韵语判词」三种腔调；反过来，同一模型给任意文本算**字符困惑度**，合以句长、对话率、虚词率、型例比四项指纹，与脂本基准对照，并查出笔意最近的回。前八十回的困惑度经过**八折交叉校验**（留十回不建模、再算那十回），以免「原著参与建模而自证其真」，另有「样本内／样本外」两条水线，免得赛跑时给自己让路。

**9. 冷暖谱：把「悲凉之雾」做成一条曲线**（`climate.html`）
逐回统计**色彩字**（红朱绛茜 ↔ 雪霜缟银冰）、**情绪字**（笑／泪／死丧／喜乐／空幻）与**繁华字**（宴戏灯）的密度，并把字镜的困惑度叠在同一条轴上；附五回平滑后的**拐点指认**，与脂批自身的悲语密度（批者在哪里先哭起来）。此谱只计字面、不计笔法：以乐景写哀之处笑声反而最密，故须与回目互参。

**10. 大观园图：空间即性格**（`garden.html`）
四十六处地点按「大观园／荣宁二府／城外寺观／江南城邑／神话仙境」分区落点，院落大小＝该处在正文中现身的次数（对数），色随类别；点一处即见居者、现身回次与写到它的诗句。园中一水为沁芳溪，自园西北贯芦雪庵、蜂腰桥、沁芳亭而入藕香榭——葬花、联句、烤鹿肉皆在水边。潇湘馆的竹与泪、蘅芜苑的藤与雪洞、稻香村的假田园，**居者—院落—诗句三者对应，即见其性格**。

**11. 草蛇灰线账本：伏线由感悟变成对账**（`clues.html`）
四十九条（十三脂批线索 + 十七判词 + 十二支曲 + 花签灯谜等）各拆为三件可查之事：**埋线**（正文最早现身处，摘录为证）→ **点破**（脂批说破处，批语为证）→ **应验**（续写哪一回接住，摘录为证）。三者俱全曰「已应」，有埋无应曰「未应」——未应者即续书之欠账，一览无余。

**12. 意象星座与批者群像**（`imagery.html` / `annotators.html`）
意象四十九类按类别分野布星，细线为同一首诗词中并见者，密者居内、疏者居外——竹—泪—潇湘一簇，花—冢—葬花一簇，雪—白—茫茫一簇。批者八本（甲戌、己卯、庚辰、戚序、蒙府、列藏、杨藏、甲辰）各作**六维画像**：悲悼、称赏、自道、洩后、篇幅、用力，并附**版本亲缘**矩阵——此书体例「后出与前者相同者不再列出」，故非对角多为空，**八本批语重合之少本身即一发现**。

## 三、好玩的地方

- **当「批者」读前八十回**（`read.html`）：勾掉甲戌、只留庚辰，看两家批语如何打架；或点「只看批语」，把小说读成一部批注史。
- **每回附白话文**（`read.html` / `continuation.html`）：正文之后有「白话文 · 本回故事」，把本回讲成几百字的现代白话小故事，**给小朋友入门用**；前八十回与后三十回续写都有，可一键收起。
- **看 AI 续书被挑刺**（`continuation.html`）：每回顶部挂「风格距离」，正文里朱批就地反驳，回末还有总评与文体计量学家的三条修改指令——**写得差的回，连批语都在嫌弃它**。
- **看诸家吵架**（`debate.html`）：探佚派拿脂批伏线，考据派拿版本异文，索隐派另有怀抱，技术组甩出统计表；主持人的裁决书决定下一回怎么写。
- **玩伏笔对照**（`graph.html`）：「伏笔—结局」视图里，前八十回埋的线（射圃、狱神庙、悬崖撒手）与推演结局两两相扣，草蛇灰线一目了然。
- **查诗谶、看诗法**（`poems.html`）：186 首诗词按体裁、作者、意象归类，谁的意象是落花秋雨、谁不作缠绵语，可比对验证。同页另附**诗法谱**七节：诗谶五十九句（逐句回原文核对，**核不中的不入谱**）、雅集年表二十场（谁在场、作何体）、逐回诗密度（前四十回几乎回回有诗，后四十回渐稀，是作者不再让他们作）、意象指纹（黛玉满纸泪花秋，宝钗偏写淡雪青云）、诗风度量四项（均句长／意象密度／虚词密度／偶句同韵率，末列「独用字」最见脾性）、韵脚谱（全书最常落在这几个字上），以及算法自陈的**存疑榜一十四首**——低置信未必是错，只是尚待人工一断。
- **看衣裳**（`costume.html`）：第四十九回一场大雪，人人一身行头——脂批一句「只一斗篷，写得前后照耀生色」，本页把谁穿着什么逐条排出与批语对读；再按服色考各人：贾母赐衣即赐分数，岫烟无氅即是穷；末尾一张**续写三十回丢下的衣单**（明写穿衣只三处，且脂本那片大红，到续写里几乎全成了青布素服）。
- **看两条谱系分野**（`versions.html`）：版本谱。脂本、甲戌本与本地汇校本止于第八十回，程甲、程乙本另有一百二十回，两谱对勘——回目相较一百二十回里七十八回题目不一，篇幅上第六十七回被程甲删去近三千字；Burrows 的 Delta 距离给出<br>**前八十回里七十七回为正、后四十回四十回无一为正，断层正落在第八十回处**；三元组交叉熵两个模型各认得自己那一半；另有「笑道」断崖（每千字 3.7 → 0.8）、疑问词「吗」后半方才当行、脂批版本分布与底本校勘记八十九条。
- **看谁最忙**（`entities.html`、`index.html`）：8944 处人物提及统计，第三回批语最密（270 条），贾宝玉在多少回里出场、香菱的泪落在哪几回。
- **算算银子**（`money.html`）：136 笔银钱从正文里逐句抽出，以刘姥姥那句「这一顿的钱够我们庄家人过一年了」为锚——**二十两即庄家人一岁之用**；月钱月例分例另成一栏，最大一笔五千两，是谁在花。
- **看节令复沓**（`calendar.html`）：十五桩节铺成十二月令环，同一个节沿径向由内而外叠珠——元宵四见（失女／归省／末次团圆）、中秋两见（起／衰音），**兴衰不用解说，看珠子多寡即明**。
- **查族谱与物色**（`tree.html` / `relics.html`）：一百二十九条关系铺成四卷世系树，八十八房各有主位、配偶、妾侍；一百一十三件器物各有其主，转手即命运——通灵宝玉、金麒麟、素服、黛玉诗稿四件被续写接住，其馀就此不提。
- **让机器替雪芹接两句**（`mirror.html`）：点「掷笔」，字符三元组接龙立刻吐出几行——「宝玉笑道：“我不过是个什么？”」骗得过一行，骗不过三段；再点「把这段送去照镜」，看它自己的困惑度几分。
- **拿别人的续书来照镜**（`mirror.html`）：把程高本某段、自己的习作、或译笔贴进去，一眼看出它离脂本几许；「全书光谱」里靛朱两色并排，前八十回与本次续写的困惑度谁高谁低，一目了然。

## 六、本地运行

```bash
pip install -r requirements.txt

# 1) 由 PDF 建库（需自备《红楼梦脂评汇校本》PDF 置于项目根，不入仓）
#    仓库已附构建好的 data/honglou.duckdb（24 张表、约 14.8 MB），可直接查询，无需重建
python -m honglou.db build

# 2) 生成静态站到 docs/
python -m honglou.site        # 之后本地起服务预览 docs/
```

涉及 LLM 的环节（推演、续写、批点）可选：在 `.env` 里配置 `VLM_API_KEY`、`VLM_BASE_URL`、`VLM_MODEL` 即可，`LLM_MIN_INTERVAL`、`LLM_MAX_RETRY` 控制限速与重试。未配置时，已落盘的语料、本体与续写成果仍可完整浏览——**站点是纯静态的，不依赖模型**。

推演、续写与批点的编排入口（需配置 LLM）：

```bash
python -m honglou.outline            # 后三十回回目与时序索引（含诸家辩论与裁决书）
python build/run_book.py 81 110      # 逐回续写（断点续跑；--force 重写，--limit N 限量）
python build/annotate_book.py 81 110 # 补脂砚斋夹批与回末总评（--force 重批）
python build/make_vernacular.py 1 110 # 每回白话文串讲（--force 重生成，--fix-long 压长稿）
python build/smoke.py                # 站点冒烟：各页面与 JSON 可访问、可解析
node build/smoke_versions.js         # 版本谱页面 JS 冒烟（最小 DOM 模拟）
```

版本谱的外部语料为可复算设计：首次分析前先取文书（网络不稳可重试，已有缓存则跳过）：

```bash
python -m honglou.witness [key]      # key：chengjia / chengyi / zhiqi / jiaxu
```

抓取结果落在 `data/witnesses/*.json`（另附 manifest 记 URL 与 sha256）；
抄本异写字的归一表见 `data/variant_map.json`，由 `build/mk_variant_map.py` 据 Unihan
变体字段与人工审定生成，统计时只数通用汉字。
