衣冠谱 · 人人身上都有文章

衣裳在《红楼》里从来不是衬着人，而是写人。本体论先立衣冠一门—— 成衣 / 首服 / 足衣 / 佩饰 / 雨具——把雀金裘、凫靥裘、猩猩毡斗篷、 白狐里鹤氅、紫金冠、抹额、掐金挖云小靴、玉针蓑……逐件录入，注明所主与托意； 再回正文把这批名物的每一次现身，连前后原文与在场之人一并钩出。 不为修辞上的好看夸张半分：色字只有在衣裳、缎绫等字的一十四字之内才算「服色」， 人名只取离它最近的那一个——换言之，此页所呈现的一切冷暖浓淡，都是可用原句复核的。
已录 97 件衣冠，正文共现身 171 处，涉及 51 回；推演三十回尚未落笔，故「待接之衣」暂不作数。

只一斗篷 · 第四十九回的雪地群像

第四十九回是全书唯一一回「人人一身行头」的群戏：一夜大雪，众姊妹披着各自的衣裳聚到稻香村。 第四十九回回末总评撮一篇短文字说得极刻薄，也极公允：

此文线索在斗篷。宝琴翠羽斗篷，贾母所赐，言其亲也；宝玉红猩猩毡斗篷，为后雪披一衬也；黛玉白狐皮斗篷，明其弱也；李宫裁斗篷是哆啰呢，昭其质也；宝钗斗篷是莲青斗纹锦，致其文也；贾母是大斗篷，尊之词也；凤姐是披着斗篷，恰似掌家人也；湘云有斗篷不穿，着其异样行动也；岫烟无斗篷，叙其穷也。只一斗篷，写得前后照耀生色。

下表把这一回里谁穿着什么逐条排出，一列是原文，一列是脂批的断语（有则有，无则留白）。 一人配一件衣裳，其人的亲疏、穷通、性情便都写在里面了。 贾母赐衣即是赐分数：赐予琴儿一件凫靥裘，众人便知老太太疼谁；岫烟一人无氅，不必再说一句穷字。

续写的服色 · 三十回里再没有一笔新的红

续写三十回里，明写「穿／披／换／脱」的只有三处：第八十一回「换衣整洁」、 第八十五回若兰「换上了射衣」、第一百五回湘莲「脱了绫罗，换了布衣」—— 而且都不是为着好看，是为了告别。 更要紧的是颜色：脂本的红，到续写里几乎不见了。下表两相对照， 并把续写里仅存的几处「红」逐条列出：其中真正属于贾家的，一笔也没有。

待接之衣 · 续写诸君的账单

凡脂本里给了托意、而本次续写（八十一回以下）不曾复现者，尽在此单。 衣裳多是细小之物，丢下一两件原不必大惊；这张单子真正的用场在另一处—— 续写者若要接住脂本的草蛇灰线，照单拿去看，一件都不会漏。
